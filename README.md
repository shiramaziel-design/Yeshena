# יֶשֶׁנָה

אפליקציית תרגול והכנה עצמאית לבחינת הבגרות בספרות, לתלמידי כיתה י"ב.

## מה יש באפליקציה

- **מושגי יסוד** — מילון מונחים ספרותיים (שירה, סיפורת, רטוריקה ולשון, פרשנות ומשמעות), עם חיפוש וסינון, כרטיסיות זיכרון (Flashcards) וחידון רב-ברירה.
- **מבנה הבחינה** — הסבר כללי על מבנה המבחן, סוגי השאלות וניהול זמן.
- **מדריך כתיבה** — עקרונות לבניית תשובה ספרותית: טענה → ציטוט → הסבר, כתיבת השוואות, ומענה לשאלות עמדה.
- **בנק תרגול** — שאלות תרגול לפי מיומנות (ניתוח שיר, ניתוח סיפור, השוואה, מושגי יסוד בהקשר, כתיבת מוקד), כל שאלה כוללת הכוונה ומחוון לבדיקה עצמית.
- **מעקב התקדמות** — כל הנתונים (כרטיסיות שסומנו, ציוני חידון, תרגילים שהושלמו) נשמרים מקומית בדפדפן (localStorage) בלבד, עם אפשרות איפוס.

> האפליקציה מתמקדת בתרגול מיומנויות ניתוח וכתיבה ספרותית. מבנה המבחן המדויק והיצירות הנלמדות משתנים משנה לשנה ולפי מסלול — יש להיצמד להנחיות המורה ולחוזרי משרד החינוך העדכניים.

## טכנולוגיה

React + TypeScript + Vite + Tailwind CSS, ממשק RTL מלא בעברית.

## הרצה מקומית

```bash
npm install
npm run dev
```

## בנייה לפרודקשן

```bash
npm run build
npm run preview
```
